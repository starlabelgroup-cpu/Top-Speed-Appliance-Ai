# Top Speed Appliance - React + Vite Website

A modern, responsive website for Top Speed Appliance repair services built with React and Vite.

## Setup Instructions

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

4. Preview the production build:
```bash
npm run preview
```

## Project Structure

- `src/` - Source code
  - `components/` - React components
  - `styles/` - CSS stylesheets
  - `assets/` - Images and logos
- `index.html` - Entry HTML file
- `vite.config.js` - Vite configuration

## Features

- Fast, responsive design
- Service showcase
- Contact form
- Modern UI with red accent color (#d10000)
